# MOOD — music for your moment

A responsive, pastel retro-pop music discovery app built for a front-end internship project. The refreshed visual theme uses baby blue, candy pink and butter yellow, with dreamy pop stickers and retro album-card details. The app uses a multi-screen layout rather than one long landing page.

## Screens
- **Discover:** featured mix, mood shortcuts and tracks.
- **Moods:** choose a feeling to filter songs.
- **Playlists:** open a playlist and view its track list.
- **Now playing:** demo controls, progress slider, next/previous and like button.
- **My profile:** liked songs and small listening stats.

Desktop uses a sidebar; mobile uses a bottom navigation bar. Navigation switches between distinct screens without requiring the user to scroll through a long page.

## Working demo interactions
- Switch screens with the navigation buttons.
- Search song titles, artists and moods in the top search field.
- Choose mood tiles and view the matching tracks.
- Open a playlist card and play a song from its list.
- Like/unlike songs and find them on the Profile screen.
- Use the player controls and seek slider. Playback is simulated; this front-end project does **not** stream real audio.
- Edit the displayed profile name.

## Files
- `index.html` — app structure and screens.
- `style.css` — visual design, responsive breakpoints and motion.
- `script.js` — navigation and demo interactions.

## Notes
The artists and song names are fictional sample content. Google Fonts are loaded from the web when available; a system sans-serif fallback is used if not.
